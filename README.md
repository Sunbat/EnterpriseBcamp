# EnterpriseBcamp

C# and MS-SQL stack practice.

## Learning Roadmap

### Phase 1 - C# Basics (current)
- [x] Variables & data types
- [x] String interpolation & formatting
- [x] Conditionals (if/else, switch expressions)
- [x] Loops (for, while, foreach)
- [x] Arrays & Collections (List, Dictionary)
- [x] Methods
- [x] Classes & Objects (OOP basics)

### Phase 2 - C# Intermediate
- [ ] Interfaces & Inheritance
- [ ] Exception handling (try/catch/finally)
- [ ] LINQ (Language Integrated Query)
- [ ] Async/Await
- [ ] File I/O

### Phase 3 - MS-SQL Basics
- [ ] Create databases and tables
- [ ] CRUD: INSERT, SELECT, UPDATE, DELETE
- [ ] JOINs and relationships
- [ ] Stored procedures & views
- [ ] Indexes & performance basics

### Phase 4 - C# + MS-SQL Integration
- [ ] ADO.NET (raw SQL from C#)
- [ ] Entity Framework Core (ORM)
- [ ] Repository pattern
- [ ] Build a small CRUD console app
